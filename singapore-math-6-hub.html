How every lesson moves

CPA is a sequence, not a menu. A student who has not held the quantity cannot draw it, and a student who cannot draw it will only memorise the symbol. Each stage engages a different channel, which is also what makes the progression work for a wide range of learners.

1

Concrete

touch · manipulation

Students handle the actual quantity before it is ever written down.

  • Place-value discs and counters
  • Fraction tiles, measuring tools
  • Balance scales for equations
  • Physical sorting and grouping
2

Pictorial

sight · spatial reasoning

The objects become a drawing that holds the same relationships.

  • Bar models: part–whole and comparison
  • Number lines and place-value charts
  • Area models and arrays
  • Tape diagrams for ratio
3

Abstract

symbol · notation

Only now does the drawing compress into numerals and letters.

  • Standard algorithms
  • Algebraic expressions and equations
  • Formulas derived, not given
  • Written justification of method

Units

Each unit file contains day-by-day lesson plans: objectives, materials, a warm-up, scripted CPA sequence, guided practice, a printable worksheet, an exit ticket, and differentiation notes. Every lesson also carries a working manipulative built for that day’s concept — discs students can trade, bars they can size, expressions they can step through.

Designed for every sixth grader

The CPA progression is already multi-sensory. These supports make that deliberate rather than incidental.

touch

Tactile equivalents

Every bar model has a physical counterpart — linking cubes, fraction strips, textured place-value discs — so a student with low vision can hold the relationship a sighted peer draws.

sight

Colour is never the only cue

Bar segments carry labels, patterns and length differences. Palette meets WCAG AA contrast and stays legible under the common colour-vision deficiencies.

hearing

Spoken model descriptions

Each lesson script includes a read-aloud description of the diagram, giving auditory learners and screen-reader users the same information as the drawing.

language

Vocabulary front-loaded

Terms are introduced with the concrete object present, supporting multilingual learners and students with language-based learning differences.

attention

Short, bounded segments

Lessons run in 5–15 minute blocks with a clear transition between each CPA stage, which reduces working-memory load and sustained-attention demand.

motor

Low-dexterity alternatives

Manipulation tasks list a partner-assisted or digital option so fine-motor difficulty never blocks access to the mathematics.
